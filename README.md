# website

outportsoftware.ca: the Outport Software site, served by GitHub Pages from `main`.

- `/` company page, `/yesteryear/` the app's help, privacy and terms (linked from the app and store listings).
- Plain HTML and one stylesheet. No build step, no cookies, no analytics, no third-party requests.
- `logo.svg` is the company mark (saltbox house over a harbour).
- Each new app gets its own folder with `index.html` (help), `privacy.html` and `terms.html`.
